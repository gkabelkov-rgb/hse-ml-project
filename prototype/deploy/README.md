# Как выложить прототипы на VPS и повесить на домен

Прототипы — обычные статические файлы (HTML + картинки). Ни базы данных,
ни бэкенда не нужно: подойдёт самый дешёвый VPS.

Что получится: по адресу `https://ваш-домен` открывается страница выбора,
`/v1/` — интерактивная вёрстка, `/v2/` — кадры из Figma.

---

## Что лежит в этой папке

```
deploy/
├── www/                ← это и заливается на сервер
│   ├── index.html          страница выбора версии
│   ├── v1/index.html       версия 1 (готова к работе сразу)
│   └── v2/                 версия 2 (кадры Figma)
│       ├── index.html
│       ├── flow.js         экраны и переходы
│       └── assets/         ← сюда положить PNG из Figma
├── nginx.conf          конфиг веб-сервера
├── deploy.sh           заливка одной командой
├── Dockerfile          вариант через Docker
└── docker-compose.yml
```

---

## Перед началом: положите кадры Figma

Для версии 2 нужны экспорты экранов. Выгрузите их из Figma
(Export → PNG, 2x) и положите в **`www/v2/assets/`**, назвав по списку из
`prototype/v2-figma/README.md` (`wb-01-poisk.png`, `site-01-kalkulyator.png`
и т.д.). Тогда кадры подхватятся автоматически у всех, кто откроет ссылку.

Если имена не совпадут — не страшно: прототип позволяет загрузить кадры
кнопкой прямо в браузере, но такие кадры видны только вам, на вашем
компьютере. Для общего доступа файлы должны лежать в `assets/`.

## Способ 1. Обычный nginx (рекомендую)

### Шаг 1. Подключитесь к серверу

```bash
ssh root@IP-адрес-сервера
```

### Шаг 2. Установите nginx

```bash
apt update && apt install -y nginx
```

### Шаг 3. Направьте домен на сервер

В панели регистратора домена (или там, где управляются DNS) создайте
запись:

| Тип | Имя | Значение |
|---|---|---|
| `A` | `proto` (или `@` для корневого домена) | IP-адрес вашего VPS |

Получится адрес вида `proto.ваш-домен.ru`. Обновление занимает от пары
минут до пары часов.

### Шаг 4. Залейте файлы

На **своём компьютере**, из этой папки:

```bash
./deploy.sh root@IP-адрес-сервера
```

Скрипт создаст `/var/www/wb-proto` и скопирует туда содержимое `www/`.
Если `deploy.sh` не запускается (Windows), скопируйте вручную:

```bash
scp -r www/. root@IP-адрес-сервера:/var/www/wb-proto/
```

### Шаг 5. Включите сайт

На сервере:

```bash
# положите nginx.conf (замените домен внутри файла на свой!)
nano /etc/nginx/sites-available/wb-proto      # вставьте содержимое nginx.conf
ln -s /etc/nginx/sites-available/wb-proto /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default        # убрать заглушку nginx
nginx -t && systemctl reload nginx
```

Проверьте: `http://proto.ваш-домен.ru` — должна открыться страница выбора.

### Шаг 6. Включите HTTPS (бесплатно)

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d proto.ваш-домен.ru
```

Certbot сам пропишет сертификат и перенаправление с http на https.
Продление автоматическое.

### Шаг 7 (по желанию). Закрыть паролем

Чтобы прототип не был доступен посторонним:

```bash
apt install -y apache2-utils
htpasswd -c /etc/nginx/.htpasswd-wb wb        # придумайте пароль
```

Затем в `/etc/nginx/sites-available/wb-proto` раскомментируйте две строки
`auth_basic` и перезагрузите: `nginx -t && systemctl reload nginx`.

---

## Способ 2. Через Docker

Если на сервере уже есть Docker, скопируйте на него всю папку `deploy/` и:

```bash
docker compose up -d
```

Прототип поднимется на порту 8080: `http://IP-адрес-сервера:8080`.
Домен и HTTPS в этом варианте удобнее навесить внешним nginx или
Caddy/Traefik.

---

## Как обновлять

Когда меняются кадры или сами прототипы — повторите шаг 4:

```bash
./deploy.sh root@IP-адрес-сервера
```

Скрипт синхронизирует папку (лишние файлы на сервере удаляются).
Если после обновления браузер показывает старую версию — обновите
страницу с Ctrl+F5 (Cmd+Shift+R на Mac).

---

## Если что-то не работает

**Открывается страница-заглушка nginx** — не удалён дефолтный сайт:
`rm -f /etc/nginx/sites-enabled/default && systemctl reload nginx`.

**403 Forbidden** — права на файлы:
`chown -R www-data:www-data /var/www/wb-proto && chmod -R a+rX /var/www/wb-proto`.

**Домен не открывается, а по IP работает** — DNS ещё не обновились
(подождите) или запись `A` указывает на другой адрес. Проверить:
`dig +short proto.ваш-домен.ru`.

**В версии 2 экраны пустые** — кадры не залиты в `www/v2/assets/`
или имена файлов не совпадают со списком.
