# Версия 2 — интерактивный прототип на реальных кадрах Figma

В отличие от версии 1 (экраны перерисованы кодом), здесь показываются
**настоящие кадры из Figma один в один**, а поверх них наложены невидимые
кликабельные зоны — как в режиме прототипа Figma.

Открывается файл **`index.html`** двойным кликом.

## Что нужно сделать (5–10 минут)

Прототип уже полностью настроен: все 40 экранов, переходы, развилка
ОТП / ВТБ и возврат в приложение работают. Не хватает только самих
кадров — их нужно выгрузить из Figma:

1. Откройте файл `Wildberries (VTB OTP)` в Figma.
2. Выделите фреймы экранов (можно сразу все — Shift + клик).
3. Панель **Export** справа внизу → **PNG**, масштаб **2x** → **Export**.

Дальше — любой из двух способов:

**Способ 1 — просто загрузить (переименовывать не нужно).**
Откройте `index.html`, нажмите вверху **«📁 Загрузить кадры»** и выберите
все PNG разом (или перетащите их прямо в окно браузера). Что совпало по
имени — встанет автоматически, остальное откроется в окне
**«Сопоставление кадров»**: напротив каждого экрана выберите нужный файл
из списка. Загруженные кадры сохраняются в браузере и остаются после
перезагрузки страницы.

**Способ 2 — положить файлы в папку.**
Скопируйте PNG в папку **`assets/`** рядом с `index.html`, назвав строго
по списку ниже. Тогда кадры подхватятся сами при открытии.

Класть можно по одному: сколько положили — столько экранов уже
отрисовывается кадрами, остальные показывают подсказку и всё равно
позволяют идти дальше по флоу. Счётчик «кадров: N из 40» вверху
показывает прогресс.

## Как пользоваться

- Клик по кнопке на кадре ведёт дальше по customer journey.
- Развилка банка — на экране «Предложения»: клик по «Продолжить» у ОТП
  ведёт в ветку ОТП, у ВТБ — в ветку ВТБ.
- Пилюля **«‹ Wildberries»** слева сверху на экранах сайта возвращает
  в приложение — на тот статус заявки, который актуален сейчас.
- На экране «Поставьте подпись» можно расписаться мышью прямо по кадру;
  кнопка «Готово» сработает только после росчерка.
- Экраны-ожидания (Госуслуги, «Готовим предложения», «Банк готовит
  договор») переключаются сами через пару секунд.

## Если зона клика промахнулась

Координаты кнопок заданы приблизительно и подгоняются за секунды:

1. Нажмите **H** (или кнопку «◱ Разметка») — все зоны подсветятся розовым.
2. Зажмите **Alt** и протяните мышью прямоугольник по нужной кнопке —
   готовые координаты скопируются в буфер и выведутся в консоль браузера.
3. Вставьте их в `flow.js` в нужный экран, в список `hotspots`, указав
   `go: 'id-экрана-назначения'`.

Переходы и id экранов там же, в `flow.js`, — файл читается как обычный
список, менять его можно без знания кода.
