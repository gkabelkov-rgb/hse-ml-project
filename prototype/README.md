# Кликабельный прототип: оформление автокредита WB × ОФМ (ОТП / ВТБ)

**Файл: `credit-flow-prototype.html`** — открывается двойным кликом в любом
браузере, интернет не нужен. Это не картинки, а живой интерфейс: поля
заполняются, чекбоксы/тумблеры нажимаются, работают маски, валидация,
слайдеры, загрузка файлов, рисование подписи и переходы между экранами по CJ.

## Что внутри

Весь путь клиента из Figma, собран в один прототип:

**Приложение WB**
- Поиск → карточка товара → лендинг «Кредит от банков-партнёров» → корзина
- «Заказы» со статусной плашкой: Заказ создан → Заявку рассматривают →
  Заявка одобрена / Заказ отменён → Внести ПВ → ПВ внесён → Подпишите договор →
  Заказ оплачен; экран «Детали заказов»
- Кнопки статусов возвращают на сайт ОФМ на актуальный шаг анкеты

**Сайт ОФМ** (мобильный)
- Калькулятор → интерстишл Госуслуг → анкета (шаги 1–4 из 7)
- Предложения (шаг 5) с развилкой банка: **ОТП** или **ВТБ**
- Оформление сделки (шаг 6): загрузка документов → (ВТБ: подписание ДКП
  онлайн на canvas) → оплата ПВ (СБП / квитанция / эквайринг)
- Подписание кредитного договора (шаг 7):
  - ОТП — в ЛК ОФМ (СМС-код), состояние «договор протух»
  - ВТБ — в ВТБ Онлайн; развилка «клиент ВТБ / не клиент» (оформление карты)
- Экран успеха «Кредит выдан» с памяткой и QR

**Возврат в приложение (как в iOS)**
На экранах сайта слева сверху — розовая пилюля **«‹ Wildberries»**: возвращает
в приложение WB на актуальный экран статуса заявки. Обратно на сайт — кнопки
в плашке «Заказов» приложения.

## Навигация по прототипу

- Все основные кнопки кликабельны и ведут по логике customer journey.
- Развилка банка — на экране «Предложения» (шаг 5): «Продолжить» у ОТП ведёт
  по флоу ОТП, у ВТБ — по флоу ВТБ.
- Серые чипсы **«⚙ демо: …»** — служебные: имитируют события, которые в
  реальности приходят по СМС/пушу (банк прислал предложения, договор готов
  и т.п.), чтобы можно было пройти путь целиком без ожидания. В продакшене их
  не будет.
- Кнопка **«↺ Сбросить прототип»** сверху — вернуться к началу пути.

## Про «1 в 1» с Figma

Экраны перерисованы вручную по макетам HTML/CSS и по вёрстке, отступам,
цветам и текстам очень близки к оригиналу. Отличия неизбежны в местах, где в
Figma использованы растровые ассеты (фотографии автомобиля и товаров, точные
фирменные логотипы банков, реальный QR) — они заменены аккуратными
CSS/SVG-стилизациями. Чтобы сделать полностью пиксель-в-пиксель, нужны
экспортированные из Figma ассеты (PNG/SVG фото и иконок); их можно подставить
на место плейсхолдеров.
